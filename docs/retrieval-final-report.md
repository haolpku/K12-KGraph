## 结论

`data/K12-KGraph` 中的公开数据可以支持“人教版小学数学课程知识图谱”的
研究、检索原型和算法评测，但不能直接视为完整、逐页可追溯的数字教材。

本次已将其中小学数学范围规范化并导入 Neo4j Community 5.26.0，完成
全文、向量、混合、参数化 Cypher、关系扩展和自动路由测试。系统技术链路
已经跑通；若用于教学产品，仍需教研人员校验知识关系、补齐节级定位和
教材证据，并复核评测集。

## 240 条小学数学在线评测

评测集覆盖 1～6 年级、上/下册、12 本人教版教材，每类 40 条：
知识点解释、教材位置、前置知识、后续知识、对应练习和相似练习。
这些标注由图数据自动生成，尚未经过小学数学教研人员人工复核。

### 实际自动路由

| 指标 | 结果 |
| --- | ---: |
| 查询数 | 240 |
| Recall@5 | 0.9986 |
| MRR | 0.9167 |
| nDCG@10 | 0.9354 |
| 平均延迟 | 8.03 ms |
| P95 延迟 | 24.22 ms |
| 失败率 | 0 |

六种意图的失败率均为 0。教材位置、前置、后续和相似题的 Recall@5 均为
1.0000；知识点对应练习为 0.9917。

### 组件对比

在全部 240 条上，关系型问题本应由 Cypher 处理，强制全文或向量方法并不
是等价实验。即使如此，混合 Recall@5 仍为 0.6792，高于全文的 0.6500
和向量的 0.6771。

更公平的实体召回子集包含知识点解释、教材位置和相似题，共 120 条：

| 方法 | Recall@5 | MRR | nDCG@10 | 平均延迟 | P95 延迟 |
| --- | ---: | ---: | ---: | ---: | ---: |
| CJK 全文 | 0.9833 | 0.9792 | 0.9803 | 5.56 ms | 12.07 ms |
| 向量 | 0.9750 | 0.9408 | 0.9551 | 11.83 ms | 16.54 ms |
| 混合 | **1.0000** | **1.0000** | **1.0000** | 19.96 ms | 30.69 ms |

混合检索以延迟增加换取了更高召回，适合模糊名称、近义描述和相似题；
确定性关系问题继续使用参数化 Cypher 更快、更稳定。

Neo4j Community 不提供本次所需的细粒度只读 RBAC 验证条件。生产应在
Neo4j Enterprise 或 Aura 创建只读账户，并设置
`NEO4J_READONLY_USER/NEO4J_READONLY_PASSWORD`；应用内部仍保留写语句
校验和 `readonly` Store 作为第二层保护。

## 建议

1. 当前数据可直接用于研究原型、知识点导航、前后置关系、代表性练习和
   混合检索算法评测。
2. 不应对外宣称“已经完整数字化人教版小学数学全部教材内容”。
3. 商用或正式教学前，补齐 Section、页码、原文证据、9/10 单元等缺口，
   并对跨册先修关系和练习题标注做教研复核。
4. 从 240 条自动生成评测中抽样扩写，形成不少于 200 条真正人工标注的
   独立验收集，避免用图本身生成问题再验证图本身造成循环验证。
